# Etapa de descoberta de requisitos do projeto

## Visão geral

Este documento deve ser base para a criação de uma aplicação de previsão do tempo. 

## Requisitos funcionais

os usuários devem ter acesso nas funcionalidades abaixo:

### Funcionalidade 1: Buscar cidades ou unidades federativas pelo nome da cidade ou pelo CEP
O usuário deve pesquisar por CEP,  por cidade ou por unidade federativa. Após a seleção da região escolhida o sistema deve buscar as informações de clima apenas da região selecionada. Caso o usuário altere a região o sistema deve atualizar a informação de acordo com a região

### Funcionalidade 2: Ver o clima atual de uma cidade ou de uma unidade federativa previamente selecionada
O usuário deve poder visualizar as informações completas do clima e para cada tipo de clima deve haver uma imagem ilustrativa

### Funcionalidade 3: Ver a previsão de 5 dias de uma cidade ou de uma unidade federativa previamente selecionada
Após a seleção de uma região o usuário pode selecinonar a opção para verificar a previsão de cinco dias a partir do dia corrente.

### Funcionalidade 4: Alternar entre Celsius e Fahrenheit


## Requisitos não funcionais

A aplicação deve garantir os seguintes requisitos não funcionais

### Usar em dispositivos móveis

### Não exigir login do usuário

### Garantir que todas as imagens e recursos utilizados não exijam sa questões de direitos autorais.

### Caso precise de acesso a localização atual, sempre perguntar ao usuário a permissão de acesso

## Riscos garantir que uma sessão de usuário não interfira em outra sessão de usuário
